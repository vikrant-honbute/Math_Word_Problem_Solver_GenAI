# 📘 Smart Math Solver (LangChain + Streamlit)

A Streamlit-based AI math word problem solver that provides clear, step-by-step explanations using LangChain agents and a calculator tool.

---

## 🚀 Features
- Solves math word problems
- Shows numbered, step-by-step reasoning
- Uses a calculator tool for accurate arithmetic
- Interactive chat-style UI
- Built using LangChain agents and Groq LLM

---

## 🛠 Tech Stack
- Python
- Streamlit
- LangChain
- Groq LLM
